# TUOBA ERP — نظام تخطيط موارد المطاعم المتكامل

نظام ERP متعدد المستخدمين للسكوبات والمطاعم والكافيهات: **خادم مركزي + مصادقة بأدوار + مخزون + منيو قابل للإدارة + ضريبة وتقارير** — بواجهة عربية/إنجليزية/فرنسية/إسبانية/تركية، **بدون أي اعتماديات خارجية** في الخادم (Node.js خالص).

## التشغيل

```bash
node server/index.js          # يعمل على المنفذ 8080 (أو PORT=xxxx)
```

ثم افتح `http://localhost:8080` وسجّل الدخول:

| المستخدم | كلمة المرور | الدور | الصلاحيات |
|---|---|---|---|
| `admin` | `admin123` | مدير نظام | كل شيء + المستخدمون + الإعدادات |
| `manager` | `manager123` | مدير تشغيل | المنيو، المخزون، المالية، الريسيبي، الاستيراد |
| `cashier` | `cashier123` | كاشير | POS، الطلبات، الكول سنتر، الحضور، المدفوعات |

> غيّر كلمات المرور فورًا من الإعدادات (بيانات الدخول التجريبية تظهر فقط في وضع demo).

## الأمان المُطبَّق

- **مصادقة**: scrypt + salt لكل مستخدم، جلسات بملفات صلاحية 7 أيام (تُخزن مُهشّرة)، إبطال فوري عند التحييد
- **تفويض**: كل نقطة نهاية تفرض أدنى دور مطلوب — العميل لا يثق به أبدًا في التسعير أو الصلاحيات
- **أسعار من الخادم**: الطلب يحمل `id + qty` فقط؛ السعر يُحل من المنيو داخل الخادم (يُهمل أي سعر من العميل)
- **تحقق مدخلات** صارم (نوع/طول/نطاق/تعداد) على كل حقل
- **CSP بدون unsafe-inline** + لا يوجد أي سكربت/معالج inline + escaping شامل للـHTML
- **حد معدل**: 5 محاولات دخول/دقيقة لكل مستخدم+IP، و140 طلب API/دقيقة لكل IP
- **سجل تدقيق** للعمليات الحساسة (دفع/استيراد/دخول/مستخدمون/مخزون) باسم المنفّذ
- **تصدير** يمنع تسريب هاشات كلمات المرور والجلسات (مُختبَر آليًا)

## المحاسبة

- الطلبات تحسب **ضريبة من الإعدادات** (افتراضي 14%) مع لقطة `taxRate` في كل طلب
- **ربح اليوم** في الرئيسية = مبيعات اليوم − مصروفات اليوم (رؤية نقدية يومية)
- **P&L الفرع/البراند** في المالية = كل المبيعات مقابل التكاليف الثابتة + المصروفات الفعلية

## الترحيل من النسخة السابقة

عند أول دخول بحساب admin، إذا وُجدت بيانات النسخة v2 المحلية (`tuoba-os-v2` في localStorage) سينتظر النظام نقرة واحدة ثم يستوردها عبر `POST /api/migrate-legacy` مع تحقق وتنظيف لكل صف.
